Ten years of shipping software across very different worlds: premium web themes sold to customers worldwide, compliance-grade systems for European businesses, ground-control software for boats, mission control for drones, the autonomy stack of ground robots used by public bodies, GPU rendering engines, and the release engineering that gets all of it out the door. The common thread is the **seams**, where most projects quietly die: research → product, simulator → real world, a stack that works → a stack someone else can operate at 3 a.m.

## 🚀 Exhibits

| | What I shipped | What it proves |
|---|---|---|
| 🧠 **Autonomy system architecture** | The software architecture of an autonomy stack for ground robots: a hierarchical safety state machine with explicit escalation, mission management, teleoperation handover, process orchestration and the HMI contract, with requirements traceable to ISO 26262 / 21448 / UL 4600 vocabulary. | The difference between a demo and a robot you can hand to an operator: every state, escalation and handover is explicit, testable and traceable to the safety vocabulary reviewers expect. |
| 🧪 **Simulation across two simulators** | Isaac Sim and CARLA in the loop with a real robot stack: digital twins and URDF → USD robots with a ROS 2 bridge on the Isaac side, scenario management and a sensor rig aligned to the real robot on the CARLA side. | You cannot iterate on a real robot. A simulator in the loop only counts if the sim-to-stack contract is honest: same topics, same sensors, same timing. I owned that contract across both simulators, including the shared-memory DDS transport that took the CARLA bridge from a CPU-bound crawl to 10 FPS across every camera and the lidar. |
| 🎥 **[Overlume](https://github.com/amerghazal7/overlume)** | Real-time third-person rendering for robots: a POD-only C++ API over Google Filament, headless, a ROS 2 node, GPG-signed releases for Linux, macOS, iOS, Windows and Android. ![release](https://img.shields.io/github/v/release/amerghazal7/overlume?style=flat-square&color=1F4FD8) ![licence](https://img.shields.io/github/license/amerghazal7/overlume?style=flat-square) | An operator needs one picture they can read while the robot moves. ~10 ms per frame at 30 Hz, from a phone to a workstation, behind an API that survives version bumps. Six ADRs, golden-image CI, seven install channels from one pipeline. |
| 🛩️ **Drone stack productionisation and mission control** | For a drone company: release workflows across flight control, mission planning and developer tooling, performance-critical C++, and a Qt/C++ mission-control application integrated with the flight controller over PX4/MAVLink. | Taking a research-grade stack to something a team can release every week, and building the operator-facing tool on top of it. |
| ⚓ **Marine ground control and docking** | Led three engineers on a C#/WinForms ground-control station over MAVLink, built a marine-craft simulation environment, and designed and simulated auto-docking and self-balancing control. | Control systems that have to hold up on water, and running a small team to deliver them in a few months. |
| 🌐 **Web products and client systems (2016 – 2022)** | Co-founded a theme studio selling premium Blogger and WordPress themes on ThemeForest; built Laravel/WordPress and Node/React systems for clients, including a DSGVO-compliant double-opt-in → CRM pipeline for a German business; later the website and ML-backed web systems of a robotics company. | Product sense and shipping to paying users since 2016, with the compliance and operations discipline that comes from running other people's systems. |
| ♿ **AI assistive system (I PUSH+)** | Secured competition funding for an AI assistive system for blind and visually impaired people. | Applied AI with a purpose, long before "physical AI" was a job title. |
| 📐 **[Systems-engineering capstone](https://github.com/amerghazal7/udacity-software-architect-nd)** | ISO/IEC/IEEE 29148 requirements, eight SysML diagrams, decision matrices and V&V suites, for the Udacity Software Architect Nanodegree (2026). | The formal method behind the instinct: requirements you can trace, diagrams a reviewer can argue with, verification that proves the design. |

Side projects: ⚡ [AxonVex](https://github.com/amerghazal7/AxonVex), a real-time C++ framework for typed processing pipelines (alpha, Apache-2.0) · 🎵 [Ghanneli](https://github.com/amerghazal7/Ghanneli), a learning prototype that pointed a spec-driven agentic workflow at AI-generated Arabic songs (MIT).
